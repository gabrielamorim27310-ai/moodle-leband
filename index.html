Como funciona

1
Grupo descreve o produto Envia um prompt detalhado para o Claude Code com a ideia, público-alvo e funcionalidades do MVP.
2
IA gera a interface O Claude Code interpreta o prompt e cria uma página HTML profissional simulando o produto.
3
MVP entra no repositório A interface é publicada aqui e o link fica disponível para todos verem.
4
Vai para o pitch deck A tela gerada é capturada e inserida no PPT do grupo para o dia do pitch.
